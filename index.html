Zona de Perigo

Esta ação vai colocar o estoque de TODOS os produtos em zero em todas as áreas (inclusive no pátio).

Recomeçar do zero

Apaga tudo o que foi cadastrado: produtos, preços, categorias, áreas, métodos de compra, receitas, histórico, cardápio digital, reservas e mapas do salão. As contas da equipe e os cargos continuam.

Antes de apagar, um arquivo de backup com todos os dados é baixado neste aparelho.

Restaurar backup

Escolha um arquivo de backup (.json) baixado pelo app. Os dados do arquivo são gravados de volta; o que já existe com o mesmo nome de registro é substituído e o resto fica como está.

Recomeçar do zero

Isto apaga todos os cadastros e dados do sistema. Não dá para desfazer (só restaurando o backup).
